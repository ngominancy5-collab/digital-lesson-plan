Week 5 · PHP

PHP Variables and Data Types

Learning objectives

  • Declare and use PHP variables correctly
  • Identify PHP's core data types
  • Apply type casting in a simple script

Introduction

Start by comparing a variable to a labelled storage box — students already met this idea in JavaScript, so anchor PHP variables to that.

Teaching content

Cover variable declaration with $, loose typing, and the string/integer/float/boolean/array types with short live-coded examples.

Teaching activities

Coding lab: students convert a static HTML form into one that stores submitted values in PHP variables and echoes them back.

Homework

Build a small script that stores a student's name, age and GPA, then prints a formatted summary sentence.
